# Customer brand assets

Brand assets are used to identify the featured organizations. All trademark rights remain with their owners.

- `unknown-university.png`: white wordmark from [Unknown University](https://www.unknown-universityas.com/), [original asset](https://irp.cdn-website.com/03b56e45/dms3rep/multi/opt/Unknown_university_Unknown-university-White+%281%29-1920w.png).
- `staffyou.svg`: [official Staffyou wordmark](https://staffyou.nl/assets/images/logos/logo.svg).
- `megathon-mark.svg`: [official Megathon icon](https://megathon.xyz/icon.svg). The accompanying MEGATHON wordmark uses Russo One, matching the typography on [Megathon](https://megathon.xyz/). The active treatment uses the site's gold accent.
- `russo-one.woff2`: Russo One from the Megathon website's public font assets, licensed under the SIL Open Font License; see `OFL-Russo-One.txt`.
- Portbase and Flowmaps reuse the original website assets in `../fluxzero/portbase-dark.svg` and `../fluxzero/flowmaps-dark.svg`.
